3. Definition of Done — DoD

✓ Kod tamamlandı
✓ Acceptance criteria karşılanıyor
✓ Unit testler geçiyor
✓ Integration testler geçiyor
✓ Lint hatası yok
✓ Code review tamamlandı
✓ Gereken dokümantasyon güncellendi
✓ Kritik bug bulunmuyor

4. Spike vs Build

Bilmiyoruz
    ↓
SPIKE
    ↓
Araştır
    ↓
Küçük prototype / PoC
    ↓
Riskleri öğren
    ↓
Teknik karar
    ↓
BUILD
    ↓
Gerçek implementation

Implementation aşamasında işleri küçük ve yönetilebilir parçalara böler, 
güvenli branch'lerde geliştirir, küçük commitlerle ilerler, 
Definition of Done ile tamamlanma kriterlerini belirler ve belirsiz teknik konularda geliştirmeden önce Spike yaparız.
